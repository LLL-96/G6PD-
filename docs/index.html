🫘 蚕豆病（G6PD 缺乏症）禁用清单

以下为禁用 / 绝对回避项。就医、买药、囤货前先核对，把这份清单给医生看。

🚨 溶血发作怎么办（先立即就医）

第一步：立即停止接触诱因
停止食用蚕豆及可疑食物；停用可疑药物；远离樟脑丸（萘）等物品。
第二步：立即送正规医院
前往医院急诊科/血液科，明确告知医生：“有蚕豆病史，怀疑溶血发作”。溶血多为自限性（1~2天，长者10天），及时处理大多可完全恢复。
第三步：途中与院内配合
保证水分供给；不要自行喂药、喂偏方；配合医生进行血常规、尿常规（看血红蛋白尿）等检查，必要时输血。

⚠️ 警惕症状（进食蚕豆/可疑药物后 1~3 天内）

  • 尿色加深，呈浓茶色或酱油色（血红蛋白尿）
  • 面色、嘴唇、指甲迅速苍白，乏力没精神
  • 皮肤、眼白发黄（黄疸）
  • 腹痛、恶心、呕吐、腰酸背痛
  • 严重时：心跳快、呼吸急、尿少，甚至休克
一句话：吃过蚕豆/可疑药物 + 尿色变深 + 发黄苍白 = 高度怀疑溶血，立即就医。

🪪 就医提示卡（可复制给医生）

患者/患儿患有 G6PD 缺乏症（蚕豆病）：红细胞易因氧化性物质破坏而发生急性溶血。用药、饮食前请核对以下禁忌：

【禁用药物】
· 解热镇痛：阿司匹林、安乃近、氨基比林、非那西丁、保泰松
· 磺胺类：复方新诺明（SMZ-TMP）、磺胺嘧啶及所有磺胺
· 硝基呋喃类：呋喃妥因、呋喃唑酮（痢特灵）、呋喃西林
· 抗疟药：伯氨喹、帕马喹（扑疟母星）、阿的平
· 其他：亚甲蓝（美蓝）、氨苯砜、萘啶酸、非那吡啶、氯霉素
· 中药成分：黄连、金银花、牛黄、珍珠末、薄荷、连翘、冰片、熊胆、腊梅花

【禁食 / 回避】
· 蚕豆及一切制品（鲜蚕豆、豆瓣酱、兰花豆、蚕豆酥等）
· 樟脑丸/卫生球/臭丸（萘）、紫药水（龙胆紫）

【慎用（需医生评估）】
奎宁、氯喹、喹诺酮类（XX沙星）、大剂量维生素C、维生素K3、磺酰脲类降糖药、复方感冒药（成分复杂，需逐项核对）

【相对安全（供参考）】
对乙酰氨基酚（常规剂量）、青霉素类 / 头孢类 / 大环内酯类抗生素

看病时请主动询问医生/药师：所开药物是否含以上禁忌成分？谢谢！
