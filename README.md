# G6PD 缺乏症（蚕豆病）禁忌速查工具

一个本地运行的小工具，帮助患者和家属快速查询**某种药品/食物/日用品对蚕豆病是否安全**。

> **免责声明**：本工具数据整理自公开权威资料（见文末来源），**仅供参考，不构成医疗建议**。一切用药请以医生处方和药师指导为准。如怀疑溶血发作，请立即就医。

## 快速开始

无需安装任何依赖，Python 3.8+ 即可运行：

```bash
cd g6pd-tool
python src/lookup.py 阿司匹林          # 查询一个
python src/lookup.py 复方新诺明 痢特灵  # 查询多个
python src/lookup.py                    # 进入交互模式（推荐日常使用）
```

## 命令速览

| 命令 | 作用 |
|---|---|
| `python src/lookup.py <名称>` | 查询药品/食物/日用品，支持别名、商品名、模糊拼写 |
| `python src/lookup.py` | 交互模式，反复查询 |
| `--list` | 浏览全部条目（按类别分组） |
| `--list --risk forbidden` | 只看禁用项（caution / safe / info 同理） |
| `--list --category food` | 按类别浏览（food=食物、tcm=中药等） |
| `--emergency` | 溶血发作应急流程（3 步救命流程 + 症状识别） |
| `--card` | 生成"就医提示卡"，看病时出示给医生 |
| `--stats` | 数据库统计 |

**健康档案（record.py）**

| 命令 | 作用 |
|---|---|
| `python src/record.py` | 总览仪表盘 + 交互菜单（推荐日常入口） |
| `python src/record.py profile` | 患者信息（含 WHO 酶活性分级录入引导） |
| `python src/record.py episode` | 溶血发作史（诱因自动比对禁忌库） |
| `python src/record.py visit` | 就诊记录（**开具药品自动比对禁忌库标风险**） |
| `python src/record.py family` | 家人 G6PD 状态（男性患者自动提示母亲检测） |
| `python src/record.py reminder` | 复查提醒（自动算下次到期日、过期红色置顶） |

档案功能亮点：
- **就诊药品自动比对**：录入药名即与禁忌库比对，禁用药红色警告“请立即与开药医生复核”，慎用药提示确认医生知情
- **智能提醒**：登记男性患者后，若母亲状态为“未查”，提示母亲做酶活性检测（X 连锁遗传，致病基因必然来自母亲）
- 数据存在本地 `data/profile.json`，纯文本可读可备份；写入采用临时文件 + 原子替换

查询结果按四级风险标注：

- ⛔ **禁用**（高风险）——明确诱发溶血
- ⚠️ **慎用**（中风险）——需医生评估后使用
- ✅ **常规可用**——常规剂量一般安全（仍遵医嘱）
- ℹ️ **提示**——疾病相关知识

标注 `[口径有分歧]` 的条目表示国内外资料意见不一（如对乙酰氨基酚、布洛芬、奎宁），说明里写了两派观点，最终以医生判断为准。

## 手机端网页版

数据与 CLI 完全同源，三个页面文件 + 数据文件，**离线可用**（无网络请求），可通过以下方式在手机上使用：

**方式一：直接打开（最简单）**
把 `web/` 文件夹传到手机（微信文件传输/数据线），点 `index.html` 用浏览器打开即可。

**方式二：电脑开服务，手机同 WiFi 访问（推荐家用）**
```bash
cd web
python -m http.server 8765 --bind 0.0.0.0
```
手机连同一 WiFi 后访问 `http://<电脑IP>:8765`（本机当前为 `http://192.168.1.48:8765`）。

**方式三：托管到公网（将来）**
`web/` 是纯静态站点，可直接部署到 GitHub Pages / Vercel / Gitee Pages 等，全家共享。

**添加到主屏幕（像 App 一样用）**
- iPhone：Safari 打开 → 分享按钮 →“添加到主屏幕”
- Android：Chrome 打开 → 右上角菜单 →“添加到主屏幕”

手机端含四个页签：🔍 查询（大搜索框 + 风险筛选）/ 📋 全部（按类别浏览）/ 🚨 应急（发作3步流程 + 症状识别）/ 🪪 提示卡（可一键复制全文发给医生）。

> 改了 `data/items.json` 后，运行 `python tools/build_web_data.py` 重新生成网页数据；运行 `node tools/test_web_search.js` 可验证网页与 CLI 搜索结果一致。

## 如何扩充数据库（后续维护）

所有数据集中在 `data/items.json`，每条是一个对象：

```json
{
  "id": "新条目英文id",
  "name": "中文通用名",
  "en": "English name",
  "aliases": ["商品名", "俗称"],
  "category": "tcm",            // 类别，见下方列表
  "risk": "forbidden",          // forbidden / caution / safe / info
  "summary": "一句话结论",
  "detail": "详细说明",
  "note": "注意事项（可留空）",
  "controversy": false,         // 口径是否有分歧
  "sources": ["S1", "S7"]       // 来源编号
}
```

类别可选值：`analgesic`（解热镇痛）、`sulfa`（磺胺类）、`furan`（硝基呋喃类）、`antimalarial`（抗疟药）、`antibiotic_other`、`cardiovascular`、`metabolic`、`neuro`、`urinary`、`other_drug`、`tcm`（中药）、`food`（食物）、`household`（日用化学品）、`occupational`（职业暴露）、`infection`（提示）。

新增来源时同步往 `sources` 数组里加一条即可。

## 分阶段路线图

**阶段一：禁忌速查 ✅**
- 79 条结构化数据，9 个权威来源
- 精确 / 别名 / 模糊查询，四级风险分级
- 应急流程 + 就医提示卡

**阶段二：健康管理档案 ✅**
- 患者信息（WHO 酶活性分级）、溶血发作史（日期/诱因/处置）
- 家人 G6PD 状态登记（X 连锁遗传，母亲检测智能提示）
- 就诊记录：开具药品自动比对禁忌库标风险、病史告知留痕
- 复查提醒（自动算下次到期日、过期置顶、一键标记完成）

**阶段三：科普模块**
- 疾病知识：WHO 分型、遗传方式、新生儿黄疸
- 就医沟通话术（怎么跟医生说病史）
- 育儿场景清单（幼儿园/旅行/疫苗接种注意事项）

**远期可选（如果将来想联网/分享）**
- 数据源升级：接入更完整的药品数据库，支持扫码/拍照识别药盒成分
- 多端形态：网页版（当前 CLI 数据可直接复用）或微信小程序

## 已知局限

- 数据为人工整理，可能不全；未收录 ≠ 安全
- 中成药成分复杂，本工具只列了已明确的中药禁忌成分
- 争议条目（controversy=true）的两派观点已注明，但最终决策请交给医生
